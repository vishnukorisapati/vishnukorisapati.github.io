# The Engine Room — Vishnu Vardhan

A responsive, working portfolio concept for Korisipati Vishnu Vardhan, developed for GitHub Pages with no build step and no external runtime dependencies.

## Preview

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

and visit http://localhost:8000.

## Interactions

- Animated, projected 3D isometric AI engine with moving execution packets, worker lights, and simulated callback updates.
- Replay/pause controls (top of website).
- Scroll-driven five-stage workflow animation, synchronized with scroll position.
- Expand/collapse engineering case studies.
- Interactive, keyboard-operable skills category tabs.
- Responsive mobile menu and readable typography.
- Reduced-motion accessibility setting respected.

## Deployment

Copy `index.html`, `styles.css`, `script.js`, and `assets/` into the root of `vishnukorisapati.github.io`, commit, and push to the default GitHub Pages branch.

## Important

Simulation visuals are demonstrations based on resume-described technologies. They do not represent live infrastructure, measured latency, or proprietary Turgo.ai architecture. No credentials, service tokens, or private code are embedded.
